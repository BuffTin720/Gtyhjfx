# Telegram Mini App — Монітор

Тёмный Telegram Mini App с поиском по 18 Telegram-источникам, категориями и разделом безопасности. Список содержит только ссылки на первоисточники; приложение не агрегирует оперативные координаты, маршруты или предполагаемые цели.

## Файлы
- `index.html` — весь интерфейс и список каналов.
- `bot.py` — небольшой запускатель Telegram-бота через Bot API: устанавливает кнопку меню Web App.
- `.env.example` — переменные окружения.
- `requirements.txt` — зависимости.

## Запуск на Android в Termux
1. Установи Python и зависимости:
   ```bash
   pkg update && pkg install python -y
   pip install -r requirements.txt
   ```
2. Скопируй `.env.example` в `.env` и укажи токен, полученный у `@BotFather`, а также HTTPS URL, где размещён `index.html`.
3. Telegram Mini App требует публичный HTTPS-адрес. Размести `index.html` на HTTPS-хостинге (например, статическом хостинге), затем впиши URL в `.env`.
4. Запусти `python bot.py`, открой своего бота и нажми кнопку меню «Відкрити застосунок».

## Настройка BotFather
Создай бота через `@BotFather` → `/newbot`, затем в `/setmenubutton` можно задать URL и текст кнопки. Скрипт также пытается установить кнопку через Bot API.

## Изменение каналов
В `index.html` найди массив `SOURCES` и отредактируй его. Username без `@`.

## Важно
Не публикуй токен бота в чатах и не добавляй его в публичный репозиторий. Веб-приложение должно размещаться на HTTPS; локальный адрес Termux сам по себе не является публичным адресом для Telegram.
